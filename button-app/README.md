# Button App

A tiny React + TypeScript app with a single button labeled "button" that
toggles its background color between green and red on click.

## Prerequisites

- Node.js 18+ (Node 24 recommended)
- npm

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

This starts the Vite dev server. Open the URL it prints (typically
http://localhost:5173/) in your browser — that's the app's entrypoint.

## Run tests

```bash
npm test
```

Runs the Jest test suite, which checks that:

1. The button renders with the label "button".
2. Clicking the button toggles its color between green and red.

## Build for production

```bash
npm run build
```
